# Доменная модель

## 1. Как делается торцевая доска

1. **Склейка №1.** Рейки разных пород клеятся кромка-к-кромке в щит.
2. **Торцовка.** Щит режется поперёк волокон на полосы. Толщина полосы = высота
   будущей доски.
3. **Поворот на 90°.** Полосы ставятся на торец — вверх смотрит торцевой срез.
4. **Склейка №2.** Полосы сдвигаются, переворачиваются, меняются местами и
   клеятся в финальную доску.
5. **(Опционально) Склейка №3+.** Нужна для 3D-кубов, «бесконечных» узоров,
   сложных мозаик.

### Следствие — главное ограничение

После шага 2 все полосы **идентичны**. Значит, в двухслойной схеме каждый ряд
итоговой доски — это одна и та же последовательность пород, максимум
развёрнутая и сдвинутая. Произвольный пиксель-арт за две склейки неизготовим.

Именно это ограничение отличает инструмент от «рисовалки квадратиков».

## 2. DSL операций

Проект = список операций над заготовкой.

```
Glue(strips: list[(species, width_mm)], length_mm)
    Склейка кромка-к-кромке. Результат — щит.

Crosscut(angle_deg: float, step_mm: float)
    Серия параллельных резов под углом angle_deg к кромке щита, с шагом step_mm.
    Каждый рез теряет kerf. angle=90° — классическая торцовка,
    45° — ёлочка/шеврон, 60° — база для кубов.

StandOnEnd()
    Поворот полос на 90° вокруг длинной оси. Торец наверх.

Arrange(order: list[int], flips: list[bool], offsets_mm: list[float])
    Пересборка полос в новый щит: порядок, отражение каждой полосы,
    продольный сдвиг.

Trim(left, right, top, bottom)
    Обрезка по периметру в размер.
```

Программа всегда чередует склейку и рез. Валидатор проверяет корректность
последовательности (нельзя `Arrange` без предшествующего `Crosscut` и т.д.).

### Как выражаются известные узоры

| Узор | Программа |
|---|---|
| Шахматка | `Glue` → `Crosscut(90°)` → `StandOnEnd` → `Arrange` со сдвигом на шаг |
| Кирпич | то же, сдвиг на половину шага |
| Ёлочка | `Crosscut(45°)` → `Arrange` с чередованием `flips` |
| Шеврон | `Crosscut(45°)` → `Arrange` без чередования |
| Кубы (tumbling blocks) | щит из 3 пород → `Crosscut(60°)` → `Arrange` со сдвигом → `Crosscut(60°)` в другую сторону |
| Диагональ | `Crosscut(θ)` с постепенным сдвигом |

Точные углы и сдвиги приложение считает само из геометрии, а не берёт из
таблицы констант.

## 3. Породы

Значения ниже — **стартовые, требуют сверки** по справочнику (The Wood Database,
Wood Handbook FPL). Плотность при влажности ~12%, кг/м³. Усушка тангенциальная /
радиальная, % от сырого до абсолютно сухого.

| Порода | Плотность | Усушка Т/Р | Цвет (примерный) | Заметки |
|---|---|---|---|---|
| Клён сахарный | ~705 | 9.9 / 4.8 | светло-кремовый | эталон для досок |
| Орех американский | ~610 | 7.8 / 5.5 | тёмно-коричневый | классика контраста |
| Вишня | ~560 | 7.1 / 3.7 | рыжевато-розовый | темнеет от света |
| Ясень | ~675 | 7.8 / 4.9 | светлый | крупные поры |
| Дуб | ~700 | 10.5 / 5.6 | светло-бурый | открытые поры, см. ниже |
| Бук | ~710 | 11.9 / 5.5 | розовато-бежевый | сильно «играет» |
| Граб | ~750 | 11.5 / 6.8 | почти белый | очень твёрдый |
| Падук | ~745 | 5.2 / 3.3 | ярко-оранжево-красный | со временем буреет |
| Амарант | ~880 | 6.1 / 3.2 | фиолетовый | цвет нестабилен на свету |
| Венге | ~870 | 8.1 / 4.8 | почти чёрный | занозы, аллерген |
| Ятоба | ~910 | 7.7 / 4.0 | красно-коричневый | тяжёлая |
| Сапеле | ~640 | 7.4 / 4.6 | красноватый | |

### Предупреждения, которые должно выдавать приложение

- **Коробление.** Если разброс тангенциальной усушки между породами в одной
  доске велик, при сезонных колебаниях влажности швы рвёт. Считаем взвешенный
  разброс и предупреждаем при превышении порога (порог подобрать эмпирически,
  начать с разницы > 3 п.п.).
- **Открытые поры.** Дуб и ясень имеют крупные сосуды, в торцевой доске они
  работают как каналы. Для разделочных поверхностей обычно не рекомендуются.
- **Аллергены и раздражители.** Венге, амарант, некоторые экзоты. Помечать
  флагом, не запрещать.
- **Цветостойкость.** Падук и амарант заметно меняют цвет. В превью можно
  показывать «через год».

## 4. Припуски и потери

- **Пропил.** Циркулярная пила: 3.0–3.2 мм стандарт, тонкий диск 2.0–2.4 мм.
  Ленточная: 1.0–1.5 мм. Настраивается пользователем.
- **Строгание.** После каждой склейки снимается 1.5–3 мм суммарно (обе стороны).
- **Обрезка кромок.** 10–20 мм по периметру после каждой склейки.
- **Итог.** Реальная закупка обычно на 25–40% больше «суммы объёмов деталей».
  Приложение обязано показывать эту дельту явно, с разбивкой по причинам.

## 5. Клей и зажим

- ПВА D3/D4. Расход ориентировочно 200–300 г/м² склеиваемой площади.
- Давление прижима для твёрдых пород — порядка 0.7–1.7 МПа. Отсюда считаем
  требуемое усилие и количество струбцин.
- Открытое время 5–10 мин, выдержка под зажимом от 30–60 мин, полная
  полимеризация 24 ч.

Все эти константы — параметры в конфиге, не магические числа в коде.

## 6. Что считаем изготовимым

Валидатор возвращает не «да/нет», а разбор:

- сколько склеек требует узор;
- какие ряды не выводятся из имеющихся щитов;
- ближайший изготовимый вариант;
- минимальная ширина детали (слишком тонкие рейки опасно пилить);
- соотношение сторон полос (риск опрокидывания при торцовке).

## 7. Ограничение области

Обратная задача (нарисованный узор → программа) решается **только для
ортогональных узоров**. Для угловых схем даём параметрические генераторы.
Это осознанное решение, а не недоделка — так и писать в README.
