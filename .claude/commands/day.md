---
description: Начать работу над днём плана
---

Открой `docs/plan.md`, найди день $ARGUMENTS.

1. Прочитай `docs/domain.md` и `docs/architecture.md`, если ещё не читал в этой сессии.
2. Сначала предложи план работ по невыполненным пунктам этого дня — не пиши код,
   пока я его не утвержу.
3. После утверждения работай по пунктам, отмечая галочки в `docs/plan.md` по мере готовности.
4. Каждый пункт закрывается тестом. `uv run pytest` должен быть зелёным перед следующим пунктом.
5. В конце добавь строку в раздел «Журнал».
